## The long-term idea

Any twisty puzzle is a permutation group acting on stickers, generated by a few rotations
of the puzzle's pieces about fixed axes. If a puzzle can be *described* - its geometry and
cuts - the suite should be able to derive the move set, then solve it either with complete
search (BFS / IDA* with automatically built pattern databases) or by learning a cost-to-go
function through self-play (DAVI needs nothing but the move function). The 2x2x2, 3x3x3
and cuboids are stepping stones that exercise every layer of that pipeline.
